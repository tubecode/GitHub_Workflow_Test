### Introduction
This script (`Hello.py`) is a lightweight academic performance tracking tool designed to automate grade analysis for educators and academic administrators. By streamlining performance calculations, it eliminates manual evaluation errors and provides immediate visibility into student achievement metrics.

---

### High-Level Overview

#### Purpose
The primary purpose of this program is to evaluate student grade data, compute individual score averages, and identify top performers to support academic reporting and recognition programs.

#### Key Functions & Business Context
* **Performance Calculation:** Automatically computes average scores across multiple assessments for each student using a reusable utility function (`calculate_average`).
* **Automated Reporting:** Generates a clean, standardized report displaying individual average scores formatted to two decimal places for clear record-keeping.
* **Top Performer Identification:** Evaluates overall performance across the dataset to instantly highlight the highest-achieving student, supporting merit awards or advanced track selection.
